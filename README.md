# Argon Proxy

Argon Proxy is an enterprise API gateway designed to enforce DPDP (Digital Personal Data Protection) compliance for AI model training pipelines. It intercepts database extracts, verifies customer AI training consent flags, applies Microsoft Presidio NLP redaction to sensitive identifiers, and injects Laplace Differential Privacy noise into numeric features for non-consenting records.

## Prerequisites

- **Python**: 3.10 or higher
- **Git**

## Setup & Installation

### 1. Clone the Repository
```bash
git clone https://github.com/Xennonite/Argon-Proxy.git
cd Argon-Proxy
```

### 2. Create and Activate a Virtual Environment

- **Windows (PowerShell):**
  ```powershell
  python -m venv venv
  .\venv\Scripts\Activate.ps1
  ```

- **macOS / Linux:**
  ```bash
  python3 -m venv venv
  source venv/bin/activate
  ```

### 3. Install Dependencies
```bash
pip install -r requirements.txt
```

> **Note:** If the spaCy language model does not automatically install via `requirements.txt`, install it manually:
> ```bash
> python -m spacy download en_core_web_lg
> ```

### 4. Initialize the Database
Generate the local SQLite database (`argon_proxy.db`) with synthetic Indian PII and DPDP consent flags from the base dataset:
```bash
python setup_db.py
```

### 5. Start the Server

> **Important (Windows / OneDrive):** When running locally with a `venv` inside the project folder, do not run `uvicorn --reload` without excluding `venv`. Otherwise, Uvicorn's file watcher will attempt to scan all 50,000+ files inside `venv` and freeze.

**Recommended command:**
```bash
uvicorn main:app
```

Or if you need auto-reload during development, exclude the `venv` directory:
```bash
uvicorn main:app --reload --reload-exclude "venv/*"
```

> **Startup Notice:** Presidio initializes the NLP model (`en_core_web_lg`) upon launch, which takes approximately 5–15 seconds to load into memory. Wait until you see:
> ```
> INFO:     Application startup complete.
> INFO:     Uvicorn running on http://127.0.0.1:8000 (Press CTRL+C to quit)
> ```

The gateway dashboard will be accessible at:
[http://127.0.0.1:8000](http://127.0.0.1:8000)

## Project Structure

- `main.py`: FastAPI server, Presidio NLP redaction engine, and Laplace differential privacy implementation.
- `setup_db.py`: Database seeding script injecting regional synthetic PII and DPDP consent flags into SQLite.
- `raw_data.csv`: Source e-commerce customer transactions dataset.
- `argon_proxy.db`: SQLite database generated by `setup_db.py`.
- `static/index.html`: Web dashboard comparing raw database records against the sanitized Argon Proxy payload.
- `requirements.txt`: Python package dependencies.
